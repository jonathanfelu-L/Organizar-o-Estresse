⚠ O Problema

Muitas pessoas acabam o dia exaustas sem entender o motivo. O problema não é a quantidade de horas — é a composição dessas horas. Uma agenda com dez reuniões seguidas esgota muito mais do que uma com quatro reuniões intercaladas por pausas.

Não existe hoje uma ferramenta simples que mostre, de forma clara e visual, o impacto acumulado de estresse ao longo do dia e permita reorganizar os horários antes que o dia comece.

RotinaCerta resolve isso: o usuário cadastra as atividades das 24 horas, informa o quanto cada uma causa ou alivia estresse, e o sistema exibe o saldo total do dia — além de ordenar a agenda automaticamente pelo horário.

🗂 Relação com Lista, Fila e Pilha

Lista

Onde é usada: agenda principal do dia.

A lista encadeada guarda todas as atividades cadastradas. Cada nó aponta para o próximo — sem tamanho fixo. O Insertion Sort percorre essa lista para colocar as atividades em ordem cronológica.

Inserção O(n)  |  Remoção O(n)  |  Ordenação O(n²)

Fila

Onde é usada: fila do dia (FIFO).

Depois de ordenar, as atividades são enfileiradas em ordem cronológica. A primeira atividade do dia é a primeira a ser processada — exatamente o comportamento FIFO. Slots vazios viram "Descanso" automaticamente.

Enqueue O(1)  |  Dequeue O(1)

Pilha

Onde é usada: histórico de ações (LIFO).

Cada ação do usuário (adicionar, remover, modificar) é empilhada. Ao desfazer, a última ação é a primeira a ser revertida — comportamento LIFO, igual ao Ctrl+Z de qualquer editor.

Push O(1)  |  Pop O(1)

Algoritmo de Ordenação — Insertion Sort

O Insertion Sort (ordenação por inserção) funciona como organizar cartas na mão. Você pega uma carta, compara com as que já estão ordenadas à esquerda, e a encaixa no lugar certo deslocando as outras.

No código, percorremos a lista com dois loops: o externo avança elemento por elemento; o interno acha onde aquele elemento se encaixa entre os já ordenados. Depois trocamos os dados dos nós para encaixá-lo.

CasoComplexidade
Melhor caso (já ordenado)O(n)
Caso médioO(n²)
Pior caso (invertido)O(n²)
Espaço extraO(1)

Para uma agenda diária (máximo 24 slots de 1 hora), O(n²) com n≤24 é rápido o suficiente e simples de entender.

📊 Critérios de Estresse

O nível de estresse vai de -10 (muito relaxante) a +10 (extremamente estressante). O sistema multiplica esse valor pela duração da atividade para calcular o impacto total no dia.

💻 Como Instalar e Executar

▸ Opção 1 — Com servidor Java (completo)

Salva os dados permanentemente no computador. Requer Java 11 ou superior.

# 1. Clone o repositório git clone https://github.com/JonathanFLuna/rotinacerta.git cd rotinacerta # 2. Compile os 3 arquivos Java javac -d out src/Estruturas.java src/Banco.java src/Servidor.java # 3. Execute o servidor java -cp out Servidor # 4. Abra no navegador http://localhost:8080

▸ Opção 2 — Direto no navegador (demo)

Sem instalar nada. Usa o armazenamento do próprio navegador (localStorage).

# Basta abrir o arquivo HTML Clique duplo em: web/index.html # OU arraste o arquivo para # qualquer navegador moderno # Os dados ficam salvos no # navegador enquanto você não # limpar o histórico

A página detecta automaticamente qual modo está ativo e se adapta.
